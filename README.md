# exocew

SecondProject — учебный репозиторий практических работ №15–16 по дисциплине «Жизненный цикл информационных систем».

Задачи ведутся в [Issues](https://github.com/exocew/SecondProject/issues). Изменения обсуждаются через [Pull requests](https://github.com/exocew/SecondProject/pulls).

## Работа с задачей

1. Прочитайте описание задачи и критерии готовности.
2. Создайте ветку от `main`, внесите изменения и отправьте ветку на GitHub.
3. Откройте pull request в `main` и запросите проверку.
4. После согласования и слияния обновите локальную ветку командой `git pull --ff-only`.
